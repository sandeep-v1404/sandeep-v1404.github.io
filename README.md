

# 🌟 My Portfolio

This is my personal portfolio website built using **React + Vite + Tailwind CSS**.
It showcases my projects, skills, and contact information in a modern and responsive design.

Live Demo 👉 [https://sandeep-v1404.github.io/](https://sandeep-v1404.github.io/)

---

## ✨ Features

* ⚡ Fast build with **Vite**
* 🎨 Styled with **Tailwind CSS**
* 🎭 Smooth animations using **Framer Motion**
* 📩 Contact form powered by **EmailJS**
* 📱 Fully responsive (works on mobile, tablet, desktop)
* 🌐 Deployed on **GitHub Pages**

---

## 🛠️ Tech Stack

* [React](https://react.dev/)

## 🚀 Getting Started

### 1️⃣ Clone the repo

```bash
git clone https://github.com/your-username/my-portfolio.git
cd my-portfolio
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Setup environment variables

Create a `.env` file in the project root:

```bash
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### 4️⃣ Run locally

```bash
npm run dev
```

### 5️⃣ Build for production

```bash
npm run build
```

---

## 🌐 Deployment (GitHub Pages)

This project is deployed using GitHub Actions.
Vite requires setting the correct `base` in `vite.config.ts`:

```ts
export default defineConfig({
  base: "/my-portfolio/", // replace with your repo name
});
```
